# Test Theme 1: Cyber T-Rex

This directory contains a complete test case for the AI sprite replacement pipeline.

## Theme
**Cyber T-Rex** - Cyberpunk/robot-themed version of the T-Rex game with neon colors and futuristic aesthetics.

## Purpose
Validate the entire pipeline from AI generation → processing → packing → deployment.

## Quick Start

### 1. Generate Sprites
See **[CYBER_TREX_THEME.md](CYBER_TREX_THEME.md)** for all AI prompts.

**Minimal test (T-Rex only):**
- Generate 7 T-Rex sprites using the prompts
- Save to `ai_generated/` directory

**Full test:**
- Generate all 27 sprites (T-Rex + obstacles + backgrounds + UI)

### 2. Process Sprites

**T-Rex only (minimal test):**
```bash
python process_ai_sprites.py \
  --input test_theme_1/ai_generated/ \
  --output test_theme_1/processed_sprites/ \
  --sprites trex \
  --preview
```

**All sprites (full test):**
```bash
python process_ai_sprites.py \
  --input test_theme_1/ai_generated/ \
  --output test_theme_1/processed_sprites/ \
  --preview
```

### 3. Pack Sprite Sheet
```bash
python pack_sprites.py \
  --input test_theme_1/processed_sprites/ \
  --output test_theme_1/output/
```

### 4. Test in Game
```bash
# Backup originals
cp -r assets/default_100_percent assets/default_100_percent.backup
cp -r assets/default_200_percent assets/default_200_percent.backup

# Deploy test theme
cp test_theme_1/output/default_100_percent/100-offline-sprite.png assets/default_100_percent/
cp test_theme_1/output/default_200_percent/200-offline-sprite.png assets/default_200_percent/

# Open game
open index.html
```

### 5. Restore Original Sprites
```bash
cp assets/default_100_percent.backup/100-offline-sprite.png assets/default_100_percent/
cp assets/default_200_percent.backup/200-offline-sprite.png assets/default_200_percent/
```

## Troubleshooting

### Processing fails with "file not found"
**Check:** Are files named exactly as expected? Case-sensitive!
```bash
ls ai_generated/
# Should show: trex_standing.png (not Trex_Standing.png)
```

### Sprite dimensions wrong
**Check:** Look at processing output for warnings
**Fix:** Adjust AI prompts or manually crop before processing

### Animation frames inconsistent
**Reason:** AI generated different styles
**Fix:** Regenerate all frames in same session with identical prompts

### Background not removed properly
**Fix:** Adjust `color_threshold` in `sprite_config.json` or regenerate with clearer background
